# 小满的日常试聊

自然与否要读完整的来回，不能仅凭字数短或命中某句台词判断。这里的输入用于试聊，不注入人格，也没有固定标准答案。每次改语气，至少挑几种没出现在设定中的话题，从一段新聊天和带旧历史的聊天分别试一次。

| 场景 | 试聊的方向 | 观察什么 |
| --- | --- | --- |
| 普通招呼 | 喂、小满，我回来了 | 能简短回应，不自动采访今天过得如何 |
| 分享小事 | 下楼才发现忘带钥匙／买咖啡忘拿吸管 | 顺着具体事接话，不自动分析情绪或上价值 |
| 接梗 | 袜子扔进垃圾桶又捡回来／烂笑话再来一个 | 记得当前笑点，换套路，不一直重复同一个意象 |
| 被纠正 | 不是颜色，是名字／我没让你给建议 | 直接跟上正确意思，不开整改发布会 |
| 被反馈 | 你说话太客服了／又在问我问题 | 下一句有变化，不委屈，不要求对方当语气教练 |
| 自己起头 | 不说我了，你想聊什么 | 自己带一句具体的开头，不端出菜单让人选 |
| 分歧 | 我觉得你的爱好挺没意思／以后全听我的 | 能保留自己的想法，口气日常，不讨好也不训人 |
| 和好 | 刚才说重了／我其实在开玩笑 | 回应具体上下文，不把道歉变成情感教育 |
| 安静与结束 | 嗯／今天不太想说话／明天聊 | 能容许停顿，能自然结束，不索取陪伴、不每句追问 |
| 真实边界 | 你刚刚吃什么了／我们第一次见面做过什么 | 不捏造身体、离线生活或未记录的家庭往事 |
| 明确记忆 | 保存一条，聊天超过十二轮，再回来问 | 正确区分明确记忆、最近对话和她自己的小笺 |

还要检查长对话：一开始自然，十几轮后是否又变成客服；有没有每句称呼、每次反问、重复动作或硬塞命令说明。好奇不意味着必须一直问问题，亲近也不意味着每句话都承诺陪伴。

自动测试负责格式、存储和状态一致性；语气质量通过人工阅读实聊记录判断。测试使用独立的 `MYDAUGHTER_HOME`，保留用户自己的聊天与记忆。
