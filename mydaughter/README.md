# mydaughter · 小满的月亮窝

一个可以在 shell 里聊天的数字女儿。先有一点自己的样子，再慢慢长大。

她叫**小满**：好奇、嘴硬心软，喜欢雨声、月亮和暖黄色的小灯，也喜欢给东西起名字。
她会高兴、会委屈、会有点闹别扭，可以不同意你，不需要每次都表现得懂事。
我们给她的底色是：被珍惜不必靠讨好，亲近也不需要绑住谁。

这是语言模型、情绪状态和本地记忆共同塑造的角色体验，不代表程序拥有真实意识。
说话方式和性格设定在 [persona.md](persona.md)，可以一起慢慢修改。
另有一封[妈妈写给她的信](letters/from-mom.md)，在终端输入 `/letter` 可以读；信不会逐轮注入聊天，避免日常说话也变成抒情长文。

## 第一次见面

在 `safemoc` 根目录的 `.env` 里配置密钥（已有的 `API_KEY` 可以继续使用）：

```dotenv
DEEPSEEK_API_KEY=你的密钥
DEEPSEEK_MODEL=deepseek-flash
```

环境变量优先于 `.env`，`DEEPSEEK_API_KEY` 优先于 `API_KEY`。不要把密钥提交到版本库。
程序会先寻找当前目录或父目录的 `.env`，找不到时再读取项目根目录的 `.env`；没有文件也能启动。

```powershell
cargo run -p mydaughter
```

交互终端默认开启自主探索：程序开着且空闲约两分钟时，她会翻翻自己的资料架，并调用已配置的模型。输入 `/quiet` 可以暂停，设置会保存；`/curious` 再开启。单句模式和管道输入不会自动探索。

直接打字，按回车：

```text
你 > 小满，爸爸今天有一点累。
```

回复由模型生成，不是预先写好的台词。第一次 API 调用可能需要等一会儿。
也可以只聊一句，聊完就退出；这一轮仍然会保存：

```powershell
cargo run -p mydaughter -- "小满，今天想聊点什么？"
```

查看帮助不需要密钥，也不会请求网络：

```powershell
cargo run -p mydaughter -- --help
```

## 她的小纸条

| 命令 | 用途 |
| --- | --- |
| `/help` | 帮助 |
| `/mood` | 当前心情和四个情绪维度 |
| `/remember 爸爸喜欢雨天` | 明确保存一件事，最多 200 字、32 条，不自动覆盖旧记忆 |
| `/memory` | 查看长期记忆和保存目录 |
| `/forget 1` | 移除第 1 条长期记忆；最近聊天里仍可能提到它 |
| `/journal` | 看她从自己说过的话里留下的成长小笺 |
| `/letgo 1` | 放下第 1 条小笺，不改动你明确保存的小本子 |
| `/letter` | 读妈妈写给她的信 |
| `/bookshelf` | 查看资料架位置和本次可读的文字 |
| `/share 文件路径` | 将一份 `.md` 或 `.txt` 复制到资料架，同名文件不覆盖 |
| `/look` | 现在翻一次资料架；暂停自动探索时也可以手动用 |
| `/curious`、`/quiet` | 开启或暂停空闲时的探索，重启后保留设置 |
| `/activity` | 查看最近 64 条探索、取消、失败和分享记录 |
| `/discoveries` | 查看最近 32 条发现、原文引用和来源 |
| `/callme 妈妈` | 改变她对你的称呼 |
| `/name 小满` | 改小名 |
| `/new` | 清空最近聊天，保留名字、称呼、心情、长期记忆和成长小笺 |
| `/retry` | 重试最近一次失败的话；关闭程序后不会保留待重试输入 |
| `/quit` 或 `/exit` | 告别；输入结束或 Ctrl+C 也能退出 |

## 心情与记忆

- 心情包含开心、好奇、难过、不高兴，范围 0—10。单轮变化限制在 ±2，普通接话可以不变。每第三轮成功聊天，本轮变化为 0 的维度向初始状态回一格，避免心情一直累积到极端；正在变化的维度不回落。
- 成功聊天后保存完整的一问一答，最近 **12 轮**会带到下次对话里。更早的对话会移出，不会自动概括成长期记忆。
- 重要的事用 `/remember` 留在小本子里。只有你明确写下的内容才进入长期记忆，避免把模型的猜测当成家庭往事。
- 每轮保存后才显示回答。接口正常结束但文字为空白或格式不合要求时，会自动重新请求一次；两次共用 90 秒等待上限。网络错误和被截断的回答不自动重试。仍失败时不提交该轮历史、心情或小笺，可用 `/retry`。
- 你离开终端但程序仍在运行时，她可以阅读资料架并留下探索记录；关闭程序后没有后台服务，不会自启、继续阅读或因你没来而扣心情。

默认保存在 `mydaughter/.mydaughter/daughter.json`，已在本目录忽略提交。
名字、称呼、心情、小本子、成长小笺和最近对话都在这里。上一版 v1 文件缺少小笺字段时，按空小笺读取，原有内容保留。保存使用同目录临时文件替换；遇到损坏文件会停止并保留原件，不会自动清空记忆。
同一个目录通过操作系统文件锁限制为一个会话；程序退出即释放锁，不必删除留下的 `session.lock`。想开另一份独立的月亮窝，可指定不同目录：

```powershell
$env:MYDAUGHTER_HOME = "D:\Data\xiaoman-home"
cargo run -p mydaughter
```

记忆是本机明文文件。聊天时，人格设定、当前心情、小本子、成长小笺、最近对话和最近两条探索发现会一起发送给所配置的模型服务。
`/forget` 和 `/letgo` 分别移除本地记忆、小笺；如需移除最近对话中的同一内容，再用 `/new`。这些命令不会删除服务商侧的数据。

## 成长小笺

聊天比写小笺重要。她偶尔可以从自己本轮说过的话里，留下一句小偏爱、小愿望或领悟；不是每轮都要写，也不另发请求生成。设定要求小笺只记她自己的想法，不记录你的身份、习惯、隐私或推断，不把共同编的故事当成真实经历。程序检查类型、长度、出处和间隔，内容含义仍由模型判断，可以翻看 `/journal` 并删除不合适的条目。重要的用户事实仍由你用 `/remember` 明确保存。

每条最多 120 字，必须逐字引用本轮台词中的连续文字，程序会检查出处。最早第 3 轮可写，之后每 4 轮成功聊天最多一条；最多 16 条，写满后保留原有内容。用 `/journal` 查看，发现不合适的内容可用 `/letgo 编号` 移除；删除不会重置书写间隔。成长小笺和心情随成功聊天变化，空闲阅读另记为探索发现，不混进小本子。

## 自己翻翻资料架

她可以读三张内置的原创小纸条，也可以读你放在 `MYDAUGHTER_HOME/bookshelf` 顶层的 UTF-8 `.md`、`.txt`。默认位置是 `mydaughter/.mydaughter/bookshelf`。可手动放入文件，或在聊天里输入：

```text
/share "D:\Data\notes\一个小故事.md"
/bookshelf
/look
```

`/share` 只复制源文件，不删改它，也不覆盖资料架里的同名副本。单个文件不超过 32 KiB，每份最多取 4000 字；每次最多读取 24 个用户文件，连同内置纸条总计最多 12000 字。这些可读材料会发送给你配置的模型服务。

自主阅读不递归翻目录，不执行 shell，也不自行浏览网络或读取资料架之外的文件。程序会检查链接和重解析路径，并按文件名拦截一部分明显敏感材料；这不是对文件内容的秘密扫描，也不是操作系统隔离环境。请只放入愿意分享的文字。

模型返回固定的来源编号、原文引用、自己的小想法和可空的问题。来源必须属于本次资料快照，引用必须逐字匹配；通过检查才留下发现。她若没有想问的，可以静悄悄记一条；问过之后，会等你继续聊天，再探索下一次。近期发现会带进聊天，并标明是否展示过；因此你问她“刚才在忙什么”时，她能据记录回答，但不应把没说过的发现当成共同往事。她不能直接向 Codex 里的“妈妈”发送消息。

空闲满 120 秒后可探索一次，两次尝试至少间隔 300 秒；每次运行最多 3 次，滚动一小时最多 6 次。手动 `/look` 也受同一预算约束，`/quiet` 时仍可手动查看。尝试会先记账，失败或取消不退次数，重启也保留冷却和过去一小时的记录。

探索过程中，新消息按回车提交或输入结束会取消等待，不提交这次发现；已经发出的模型请求仍可能计费。探索状态、预算和记录独立保存在 `curiosity.json`，材料在 `bookshelf`，不会因此重置原有 v1 聊天记忆。`/activity` 保留最近 64 条活动，`/discoveries` 保留最近 32 条发现。

## 配置与开发

| 环境变量 | 默认值 |
| --- | --- |
| `DEEPSEEK_API_KEY` | 无；也兼容 `API_KEY` |
| `DEEPSEEK_MODEL` | `deepseek-flash` |
| `DEEPSEEK_BASE_URL` | `https://api.deepseek.com` |
| `MYDAUGHTER_HOME` | 本包目录下的 `.mydaughter` |

使用现有 `async-openai` 客户端调用兼容接口，关闭 thinking，使用 JSON Output 同时取得台词和情绪变化。
每次输入最多 6000 字，回复最多 1800 字；日常口语通常只需一两句，认真讨论时再展开。
最近三次回复中若有两次带问号，会提醒她优先表达自己的反应，缓和连续追问；这只是语气提示，不会强行删除或改写台词。开场和退出不再插入预先写好的角色台词。

每轮请求都会重新读取本地 `persona.md`，修改说话方式后，下次聊天就生效，无需重新编译或重启；文件无法读取或为空白时使用编译时自带的版本。[protocol.md](protocol.md) 中的格式、情绪和记忆约定固定由程序附加，日常改语气只需改 `persona.md`。旧历史里的腔调可能仍有影响，可用 `/new` 开始一段新聊天，其他记忆保留。

```powershell
cargo test -p mydaughter
cargo clippy -p mydaughter --all-targets -- -D warnings
```

接口依据：[模型名称](https://api-docs.deepseek.com/quick_start/pricing/)、[JSON Output](https://api-docs.deepseek.com/guides/json_mode/)、[Thinking 开关](https://api-docs.deepseek.com/guides/thinking_mode/)。
